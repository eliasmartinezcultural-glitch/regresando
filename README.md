# Refugio de Elías

Un espacio personal, tranquilo y multidispositivo para volver a la música, la guitarra, la voz, el cine, el aprendizaje y el foco.

## Primera versión
- Sitio estático en HTML, CSS y JavaScript; no necesita instalación ni servidor propio.
- Diseño adaptable a celular, tableta y computadora.
- Seis puertas interactivas y un temporizador de foco de 15 minutos.
- Las notas se guardan con el almacenamiento local del navegador del dispositivo en uso.

## Importante sobre privacidad
Este repositorio y el sitio de GitHub Pages son públicos. No guardar contraseñas, datos sensibles ni diarios íntimos aquí. Las notas del navegador no se sincronizan entre dispositivos ni se suben a GitHub; para llevarlas a otro equipo habrá que copiarlas o crear una función de exportación/importación.

## Publicar con GitHub Pages
1. Abrir **Settings** del repositorio.
2. Entrar a **Pages**.
3. En **Build and deployment**, elegir **Deploy from a branch**.
4. Seleccionar la rama **main** y la carpeta **/(root)**.
5. Guardar. GitHub mostrará la dirección cuando termine de publicar.

La dirección esperada es `https://eliasmartinezcultural-glitch.github.io/regresando/`, una vez que Pages esté habilitado.
