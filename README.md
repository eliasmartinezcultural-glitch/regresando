# El Refugio

Una experiencia digital tranquila, de inspiración rural patagónica. Sitio estático para GitHub Pages.

## Principios
- Acceso directo, sin cuenta ni contraseña.
- Sin publicidad, pagos obligatorios ni servidor propio.
- Diseño adaptable a teléfonos, tabletas y computadoras.
- Interacciones asociadas a objetos de una escena ilustrada.
- Notas guardadas solo en el navegador y dispositivo actuales.
- Reproductores para enlaces de YouTube y archivos de audio/video compatibles.
- El contenido externo requiere conexión y puede bloquear la reproducción incrustada.

## Publicación
Configurar GitHub Pages para publicar la rama `main` desde la raíz del repositorio.

## Estado
Reconstrucción total de la página principal. La experiencia visual, el patio conectado y una selección de contenido con licencias adecuadas continuarán evolucionando por etapas.
